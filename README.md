# Al-Aseel Currency Converter 💱

This project is focused on **currency conversion** and **exchange rate calculation**, allowing users to convert money between different currencies easily and accurately. It includes several additional features to make the experience simple and interactive.

## About

The main goal is to **transfer money** and calculate conversions using the latest exchange rates. The interface is built with **HTML, CSS, and JavaScript**, making it responsive and user-friendly.

## Features

- Convert multiple currencies
- Real-time exchange rate calculation
- Easy-to-use interface
- Modern design with interactive elements

## Technologies Used

- **HTML** for structure  
- **CSS** for styling  
- **JavaScript** for conversion logic
